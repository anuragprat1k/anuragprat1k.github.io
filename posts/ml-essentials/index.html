Transformers#

RNNs h_t = tanh(W_h . h_{t-1} + W_x . x_t + b) y_t = softmax(h_t) suffer from vanishing / exploding gradients for long sequences

LSTM is a special type of RNN that fixes the short-term memory problem. has cell states and gates (forget, input and output gates) sequential - computation at time t depends on t-1, hence slow

Transformers - core mechanism is self-attention looks at all words together softmax(Q.K_t / sqrt(d_k)) . V needs positional encoding to encode positions

Multi-Head Attention vs Grouped Query Attention in MHA there are h heads and h sets of Q,K,V matrices in GQA, fewer kv heads. A group of query heads share the same KV heads KV heads don’t need to be as diverse as queries. Q - what you are interested in K - offering context V - actual information

MHLA (Multi head latent attention) a fixed set of latent queries attend to the input token instead of input x, which allows them to extract high level value allows complexity to be O(n.l) where l « n

MoE more capacity at comparable inference cost in a normal feedforward layer x → Linear → ReLU → Linear → output FFN is replaced with multiple experts x → Gating(x) → top-2 experts → outputs combined → rest of Transformer gating selects the top k experts target FFNs since they comprise ~70% of the compute FFN is costly because it expands d_model to 4x d_model for more representational power

Pre-norm residual = x x = SelfAttention(LayerNorm(x)) x += residual

RoPE apply a rotation to the q and k vectors based on a frequency (controls the rotation) 2D rotations to pairs of dimensions - why? variation in frequency is across the embedding dimension

KV Caching inference trick to save K,V
