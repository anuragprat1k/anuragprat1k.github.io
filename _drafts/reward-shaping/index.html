Reward Shaping in Reinforcement Learning

March 20, 2026

Introduction#

A fundamental challenge in reinforcement learning is specifying what we want an agent to do. The reward function encodes this objective, but in practice, designing good reward functions is notoriously difficult. Reward shaping — the practice of modifying or augmenting the reward signal to accelerate learning — is one of the oldest and most important techniques for addressing this.

The Problem: Sparse Rewards#

In many environments, the natural reward signal is sparse. A game of chess provides a $+1$ or $-1$ only at the end; a robot learning to navigate receives reward only upon reaching the goal. With sparse rewards, the agent must rely on random exploration to stumble upon success before it can begin to learn — a process that scales poorly with the size of the state space.

Potential-Based Reward Shaping#

The seminal work by Ng, Harada, and Russell (1999) formalized reward shaping and established conditions under which it preserves the optimal policy.

Given a potential function $\Phi: S \rightarrow \mathbb{R}$, the shaped reward is:

$$F(s, a, s’) = \gamma \Phi(s’) - \Phi(s)$$

where $\gamma$ is the discount factor. The key result: any MDP with potential-based shaping has the same set of optimal policies as the original MDP. This is a powerful guarantee — it means we can inject domain knowledge to speed up learning without worrying about introducing sub-optimal behavior.

Intuition#

The potential function acts like a heuristic in search. If $\Phi(s)$ is higher for states closer to the goal, transitions toward the goal receive positive shaping reward, and transitions away receive negative shaping reward. The agent gets denser feedback while still converging to the same solution.

Beyond Potential-Based Shaping#

While potential-based shaping is theoretically clean, practitioners often use richer forms of reward shaping:

  • Distance-based rewards: Reward proportional to progress toward a goal (e.g., negative distance to target). Simple but can create local optima.
  • Curriculum-based shaping: Gradually increase task difficulty, effectively reshaping the reward landscape over time.
  • Intrinsic motivation: Reward curiosity or novelty (e.g., ICM, RND) — a form of automatic reward shaping driven by prediction error.
  • Reward learning from demonstrations: Use inverse RL or preference-based methods to learn a reward function, which can be seen as data-driven reward shaping.

Pitfalls#

Reward shaping is powerful but introduces risks:

  1. Reward hacking: The agent may exploit the shaped reward in unintended ways, achieving high shaped reward without solving the actual task.
  2. Non-potential-based shaping can change the optimal policy: Without the theoretical guarantees of potential-based shaping, there is no assurance that the agent will converge to the right behavior.
  3. Over-shaping: Too much shaping reward can dominate the true reward signal, effectively replacing the original objective.

Connection to RLHF#

Reward shaping ideas are deeply relevant to RLHF for language models. The reward model trained on human preferences is itself a form of learned reward shaping — it provides a dense signal (per-token or per-response) that would otherwise be extremely sparse (humans can only evaluate so many outputs). The KL penalty in RLHF can also be viewed through a reward-shaping lens, acting as a potential-based term that regularizes toward the reference policy.

Open Questions#

  • How should we shape rewards in multi-agent or multi-objective settings?
  • Can we automatically discover good potential functions from data?
  • What is the right balance between shaping density and fidelity to the true objective?
  • How do reward shaping insights apply to reasoning models trained with process rewards?
